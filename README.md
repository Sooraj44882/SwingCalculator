## How to Run

 Requirements

- Java 21 or later


### Windows

1. Download and install latest Java   JDK from [Eclipse Temurin](https://adoptium.net/temurin/releases/?version=21).
2. Select Windows, x64, JDK, and download the `.msi` installer.
3. Run the installer and complete the installation.
4. Open Command Prompt and verify the installation:

   ```bash
   java -version
   ```


**if you java install already start from below**

5. Extract the downloaded Dcalc ZIP file.
6. Double-click `run.bat` to launch the calculator.


### macOS

1. Download Java latest JDK from [Eclipse Temurin](https://adoptium.net/temurin/releases/?version=21).
2. Select macOS, choose the correct architecture for your Mac, and download the `.pkg` installer.
   - **Apple Silicon:** Choose AArch64 for M1, M2, M3, M4, or newer Apple Silicon Macs.
   - **Intel Mac:** Choose x64.
3. Open the installer and follow the instructions.
4. Open Terminal and verify the installation:

   ```bash
   java -version
   ```

**if you java install already start from below**

5. Extract the downloaded Dcalc ZIP file.
6. Open the extracted Dcalc folder in VS Code:
   - In the terminal, run:

   ```bash
   chmod +x run.command
   ./run.command
   ```

  Make sure you open the main project folder containing `run.command`, the Java class files, and the `lib`, `asset`, and `d` folders.
